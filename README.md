# LUCKY.DEV

Персональный сайт-портфолио на чистых HTML, CSS и JavaScript.

## Запуск на Windows

1. Распакуйте архив в удобную папку, например `C:\Users\ВашеИмя\Desktop\LUCKY-DEV`.
2. Откройте Visual Studio Code.
3. Выберите **File → Open Folder...** и откройте папку `LUCKY-DEV`.
4. Откройте `index.html`.
5. Для удобного локального просмотра установите расширение **Live Server**:
   - откройте Extensions (`Ctrl + Shift + X`);
   - найдите `Live Server` от Ritwick Dey;
   - установите;
   - нажмите правой кнопкой по `index.html` → **Open with Live Server**.

Можно также открыть `index.html` двойным щелчком в Проводнике. Live Server удобнее при редактировании, так как автоматически обновляет страницу.

## Структура

- `index.html` — разметка и содержание всех секций.
- `css/styles.css` — оформление, адаптивность и анимации.
- `js/app.js` — мобильное меню, текущий год и эффекты появления.
- `assets/favicon.svg` — иконка сайта.

## Что изменить под себя

Откройте `index.html` и найдите:
- `Lucky` — имя/псевдоним;
- тексты в блоках About, Projects и Contact;
- ссылки `https://t.me/kogot_lucky`, GitHub и YouTube.

Список проектов сейчас задан прямо в HTML. Чтобы добавить проект, скопируйте целиком один блок `<article class="project-card">...</article>` внутри `#projectGrid`, затем замените название, описание, категорию и ссылку.

## Публикация через GitHub Pages

1. Создайте новый публичный репозиторий на GitHub, например `lucky-dev`.
2. Загрузите в корень репозитория `index.html`, а также папки `css`, `js` и `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации GitHub покажет адрес сайта вида `https://ВАШ-АККАУНТ.github.io/lucky-dev/`.

## Важно

- Сайт статический: сервер и база данных для текущей версии не требуются.
- Статусы проектов `IN DEVELOPMENT` — текстовые метки, а не проверка реального состояния проекта.
- Google Fonts подключаются через интернет. При отсутствии соединения применятся системные шрифты.
- Данные о музыке, онлайн-статусе и GitHub-активности пока не подключены к API; это можно добавить отдельным этапом.
